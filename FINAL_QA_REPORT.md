## 4. Chapter 5

The structure follows Nazi's Chapter 5: introduction → answers per research question → for each class, a summary of both phases, a rank-comparison table, then discussion → recommendations → limitations → future research.

Each class section now covers:
- explanation;
- comparison with prior studies;
- agreement or disagreement;
- a possible reason, stated as possible where the data cannot decide;

The new sources are used only for comparison, and each comparison states the limits of what the evidence can show. For example:
- the Gen Z comparison notes that the data come from managers, not users;

## 6. Formatting applied (guide `shivehnamehpn` as the standard)

**Page setup**
- A4 paper.
- Margins: right 3.5 cm, top 3.5 cm, left 2.5 cm, bottom 2.5 cm.

**Spacing**
- Body line spacing exactly 1 cm.
- Abstract line spacing 1.5 cm.
- Images use automatic spacing so they are not clipped.

**Front matter**
- Order: بسمله page → title page → dedication → Persian abstract → table of contents → list of tables → list of figures.

**Captions and numbering**

- Table captions above the table; figure captions below the figure.
- All tables and figures are referenced in the text.

**Numbers in running text**

- Decimal separator «/» (for example ۰/۴۲۹).

**Reference list**
- Persian references first, then English.
- Each group in alphabetical order, with a hanging indent.

**Back matter**
- English abstract (296 words).
- English title page following the guide template ("Under Supervision of", "A thesis submitted to the Graduate Studies Office in partial fulfillment of the requirements for the degree of Master of Science in …").

**Metadata**
